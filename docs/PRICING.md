# Pricing

Media Ark has two product paths: the free local-only [4444J99/media-ark](https://github.com/4444J99/media-ark) repository and a paid Pro tier for encrypted cloud sync and backup.

## Free

**Price:** $0

The free repository is local-first. Captures, OCR output, manifests, indexes, reports, and dashboard state stay on the machine where Media Ark runs.

Use Free when:

- you want a private local media archive;
- you are evaluating the pipeline;
- your existing backup system already covers `.media-ark/`;
- you prefer repository-based automation without any hosted service.

Included:

- CLI ingest and processing;
- local dashboard, API, and MCP surfaces;
- local OCR/metadata enrichment;
- local manifests, indexes, reports, and event logs.

## Pro

**Price:** $7/mo

Pro is for knowledge workers and journalists who treat captured media as working evidence: screenshots from research, PDFs from public records, interview material, photos, scanned documents, filings, notes, and source packs that need to remain searchable and recoverable over time.

Pro adds encrypted cloud sync and backup to the local-first workflow. The goal is simple: keep the working archive available when a laptop is replaced, a field device is lost, or a project needs to move between machines.

Included:

- everything in Free;
- encrypted cloud sync for archive state;
- encrypted cloud backup for recovery;
- restore support for processed assets, manifests, indexes, metadata, and reports.

## Tier Comparison

| Capability | Free | Pro |
| --- | --- | --- |
| Local ingest and processing | Yes | Yes |
| Local dashboard, API, and MCP | Yes | Yes |
| Local manifests, indexes, and reports | Yes | Yes |
| Encrypted cloud sync | No | Yes |
| Encrypted cloud backup | No | Yes |
| Archive recovery across devices | Manual | Included |
| Price | $0 | $7/mo |

## Value for Knowledge Workers and Journalists

Media Ark is built for people whose source material accumulates faster than it can be manually organized. Pro makes that archive more durable without changing the local-first operating model.

For a researcher, analyst, attorney, journalist, or editor, the value is:

- less risk of losing source context when work moves across devices;
- faster recovery of searchable project history after hardware failure;
- a consistent archive of original files, OCR text, metadata, reports, and processing history;
- a practical backup path for deadline-driven work where recreating source collections is expensive or impossible.

Free is the right default when local storage is enough. Pro is the upgrade when the archive has professional value and needs encrypted off-machine continuity.
