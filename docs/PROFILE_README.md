# Product Profile: Media Ark

This repository is focused on automating long-running, manual media triage tasks into deterministic daily automation.

## Core Promise
- Detect new media (images, video, PDF, documents) quickly.
- Process and canonicalize assets once.
- Enrich with OCR + metadata for searchable retrieval.

## Why this exists
One-day capture cleanup tasks become noise quickly. This project turns them into a reproducible pipeline that can run locally, unattended, and recoverably.
